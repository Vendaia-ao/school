# Design System — Vendaia School®

Sistema de gestão escolar enterprise. Estética: **Corporate Modernism** — densidade alta, hierarquia clara, paleta navy + laranja, sem floreados decorativos. Prioridade: legibilidade de dados sobre ornamento.

## 1. Cores (tokens Tailwind em `src/index.css` → `@theme`)

Usar EXCLUSIVAMENTE os tokens semânticos abaixo. Nunca usar cores Tailwind genéricas (`bg-blue-500`, `text-gray-600`) nem hex diretos inline — usar os tokens.

### Estrutura / Navegação
- `primary` `#041939` — navy profundo. Sidebar, branding, títulos de página, cabeçalhos de tabela.
- `primary-container` `#061b3b` — fundo da sidebar (ligeiramente diferente do primary).
- `on-primary` `#ffffff` — texto/icones sobre primary.
- `on-primary-container` `#7284a9` — texto secundário na sidebar.

### Ação / Destaque
- `secondary` `#a04100` / `secondary-container` `#fe6b00` — laranja vibrante. USAR COM PARCIMÓNIA: botões primários de ação (e.g. "Emitir", "Adicionar", "Confirmar"), estados ativos de menu, links de destaque ("Ver todos"), e o accent de 2px no menu ativo. Nunca usar laranja para texto corrido ou fundos grandes.
- `on-secondary` `#ffffff` — texto sobre secondary.

### Surfaces (camadas tonais, do claro ao escuro)
- `background` / `surface` `#f8f9fa` — fundo da página.
- `surface-white` `#ffffff` — cartões de conteúdo, modais, dropdowns.
- `surface-container-low` `#f3f4f5` — hover de linhas, fundos de sub-painéis, inputs aninhados.
- `surface-container` `#edeeef` — separadores suaves.
- `surface-container-high` `#e7e8e9` — estados desativados.
- `surface-container-highest` `#e1e3e4`.

### Texto
- `on-surface` `#191c1d` — texto principal.
- `on-surface-variant` `#44474e` — texto secundário/descritivo.
- `outline` `#75777f` — labels, captions, texto terciário.
- `outline-variant` `#c5c6cf` — bordas discretas.

### Bordas
- `border-subtle` `#E5E7EB` — borda padrão 1px de cartões, tabelas, inputs.
- `outline-variant` `#c5c6cf` — borda mais visível (hover, foco).

### Semânticas (status)
- `success` `#16A34A` — ativo, pago, regularizado, aprovado, estável.
- `warning` `#F59E0B` — pendente, parcial, abaixo da meta, expiração próxima.
- `error` `#DC2626` — inativo, dívida, atrasado, reprovado, crítico.
- `info` `#2563EB` — emitido, informativo, neutro.

### Padrão de status chips/badges
Sempre: **fundo a 10-15% de opacidade da cor semântica + texto a 100% da mesma cor.**
```
<span className="bg-success/10 text-success px-2 py-0.5 rounded-full text-[10px] font-bold">Ativo</span>
<span className="bg-warning/15 text-warning px-2 py-0.5 rounded-full text-[10px] font-bold">Parcial</span>
<span className="bg-error/15 text-error px-2 py-0.5 rounded-full text-[10px] font-bold">Atrasado</span>
```

## 2. Tipografia

Fonte única: **Hanken Grotesk** (`--font-sans`). Sem variar fontes. Máx 3 pesos por ecrã (400, 600, 700).

| Token | Tamanho | Peso | Uso |
|---|---|---|---|
| `headline-lg` | 32px | 700 | (raro) títulos de landing |
| `headline-md` | 24px | 600 | títulos de modal grande |
| `headline-sm` | 20px | 600 | valores KPI grandes |
| `title-lg` | 18px | 600 | título de página, título de painel |
| `body-lg` | 16px | 400 | texto corrido (raro neste projeto) |
| `body-md` | 14px | 400 | texto descritivo |
| `label-md` | 13px | 500 | labels de botões, items de menu |
| `label-sm` | 11px | 600 | badges, breadcrumbs |
| `caption-xs` | 10px | 700 | **headers de tabela, títulos de KPI** — ALL-CAPS, tracking-wider |

Regras:
- **KPI labels e table headers são SEMPRE** `text-[10px]` ou `text-[11px]`, `uppercase`, `font-bold`, `tracking-wider`, cor `text-outline` ou `text-on-surface-variant`.
- Títulos de página: `font-title-lg text-2xl font-bold text-primary`.
- Valores KPI: `text-2xl font-bold text-primary leading-none`.
- Texto de tabelas: `text-xs` (12px) para dados, `text-[11px]` para headers.
- Não usar font-size > 32px.

## 3. Layout & Espaçamento

### Estrutura global
- **Sidebar fixa** à esquerda: expandida `w-[260px]`, recolhida `w-[80px]`. Fundo `bg-primary-container`, texto `text-on-primary-container` / `text-on-primary`.
- **Header** fixo no topo: `h-header-height` (48px), `bg-surface-white/90 backdrop-blur-md`, `border-b border-border-subtle`, `shadow-sm`. Contém breadcrumb à esquerda, controlos à direita.
- **Conteúdo principal**: `mt-header-height p-4` (ou `p-6`), `max-w-7xl mx-auto` (ou `w-full`), `flex flex-col gap-3`.

### Espaçamento
- Grid base: **8px**. Gutters entre cartões: `gap-3` (12px) ou `gap-4` (16px).
- Padding interno de cartões: `p-4` (16px) ou `p-3` (12px).
- Padding externo da página: `p-4` (16px).
- Altura padrão de KPI card: `h-[68px]`.
- Altura padrão de painel de gráfico: `h-[300px]`.

### Grid responsiva
- KPI cards: `grid grid-cols-1 md:grid-cols-4 gap-3`.
- Gráficos: `grid grid-cols-1 md:grid-cols-3 gap-3` (gráfico principal `col-span-2`, secundário `col-span-1`).
- Cards de relatório: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-3`.

## 4. Raio (border-radius)

**CRÍTICO** — o `src/index.css` força estes valores globalmente. Respeitar a hierarquia:

| Elemento | Raio | Classe |
|---|---|---|
| Cartões estruturais, painéis, tabelas, modais | **1px** (quase retangular) | `rounded-xl` / `rounded-lg` (override global p/ 1px) |
| Botões, inputs, selects, badges, chips, status pills | **4px** | `rounded-md` / `rounded-sm` / `rounded-full` (override global p/ 4px) |
| Donut chart e inner container | **12px** (exceção explícita) | `rounded-12px` / `.chart-donut-box` |
| Avatares e notification dots | **circular** | `rounded-full` (mantém) |

Nunca usar `rounded-2xl`, `rounded-3xl` — o CSS força a 1px. A estética é **conservadora/retangular**, não arredondada.

## 5. Elevação & Sombras

Sombras **ultra-discretas** (definidas em `index.css`):
- `shadow-sm` — cartões e header (default na maioria dos painéis).
- `shadow-md` — hover de cartões (`hover:shadow-md`).
- `shadow-lg` — dropdowns.
- `shadow-xl` / `shadow-2xl` — modais.

Hover de linhas de tabela e items: mudança de `bg-surface-container-low/30` (não elevação). Manter sensação plana e estável.

- Estado vazio: `<td colSpan={N} className="text-center py-8 text-on-surface-variant font-medium">Nenhum resultado.</td>`.
- Ações: botões icon-only `p-1.5`, cor outline → hover com cor semântica + fundo a 10%.

### 6.6 Modal
```tsx
{isOpen && (
  <div className="fixed inset-0 bg-black/50 z-50 flex items-center justify-center p-4 overflow-y-auto">
```

Regras do modal:

- Container: `bg-surface-white rounded-xl shadow-2xl border border-border-subtle`, `max-w-md`/`max-w-2xl`/`max-w-lg`.

- Footer: botão secundário (border) à esquerda, botão primário (bg-secondary) à direita.

## 7. Ícones

Duas bibliotecas em uso — manter consistência:
- **lucide-react** — ícones de ações e conteúdo (Search, Plus, Receipt, Wallet, Printer, etc.). Sempre `stroke-[2]` (ou `stroke-[1.75]` em casos densos). Tamanhos: `w-4 h-4` (tabelas), `w-5 h-5` (modais), `w-6 h-6` (títulos).
- **Material Symbols Outlined** — ícones de navegação/sidebar e ícones utilitários inline. Usar via `<span className="material-symbols-outlined text-[18px]">icon_name</span>`.

Regra: num mesmo ecrã, não misturar as duas bibliotecas para o mesmo propósito. Sidebar → Material Symbols. Conteúdo/ações → lucide-react.

## 8. Estados & Micro-interações

- **Hover de cartão**: `hover:shadow-md` (subtil).
- **Hover de linha de tabela**: `hover:bg-surface-container-low/30 transition-colors`.
- **Hover de botão icon**: mudança de cor de texto + fundo semântico a 10%.
- **Tab ativo**: `border-t-2 border-secondary` + fundo branco.
- **Menu sidebar ativo**: `text-on-primary bg-on-primary-container/20 border-l-2 border-secondary font-semibold`.
- **Transições**: `transition-all` ou `transition-colors`, duração default do Tailwind (150ms).
- **Animações de entrada**: usar `motion` (framer-motion) quando apropriado para modais e drawers, mas manter subtil.
- **Tooltips**: classe `.has-tooltip` com `.tooltip` (definida em `index.css`).

## 9. Scrollbar

Scrollbar customizada (definida em `index.css` para drawers): `6px` de largura, track transparente, thumb `#E5E7EB` com `4px` de raio.

## 10. Estrutura de um Ecrã Completo (ordem)

Todo ecrã de módulo segue esta ordem top-to-bottom:
1. **Banner de título** com tags de módulo + título + descrição + botão de ação principal.
2. **KPI Cards** (4 colunas em desktop): métricas-chave do ecrã.
3. **Painel principal com Tabs** (se o ecrã tiver sub-seções) OU painel único com tabela/conteúdo.
4. **Barra de pesquisa & filtros** acima da tabela.
5. **Tabela de dados** com ações por linha.
6. **Modais** para criar/editar/pagar (overlay `bg-black/50`).
7. **Toast** para feedback de ações.

## 11. Regras de Ouro

1. **Densidade sobre espaço em branco** — este é um sistema enterprise. Padding apertado, texto pequeno (10-14px), muita informação por ecrã.
2. **Laranja (secondary) é escasso** — apenas para a ação principal do ecrã, estados ativos, e destaques. Nunca para fundos grandes.
3. **Navy (primary) é a âncora** — sidebar, títulos, headers de tabela, valores importantes.
4. **1px de raio nos estrutural, 4px nos interno** — nunca arredondar cartões ou modais. A estética é retangular.
5. **Sombras quase invisíveis** — `shadow-sm` é o default. Hover só eleva ligeiramente.
6. **Status cores semânticas com fundo a 10-15%** — nunca usar a cor sólida como fundo de chip.
7. **Labels ALL-CAPS, tracking-wider** — KPI labels e table headers são sempre maiúsculas e pequenas.
8. **Português de Angola/Portugal** — toda a UI está em PT. Manter terminologia institucional ("matrícula", "propina", "encarregado de educação", "emolumentos").
9. **Consistência entre módulos** — um ecrã do módulo financeiro deve ser visualmente idêntico a um do módulo académico. Mesmas KPI cards, mesmas tabelas, mesmos modais, mesmas tabs. Apenas muda o conteúdo.
10. **Não inventar componentes** — se um padrão já existe (KPI card, tabela, modal, tab, filtro), reutilizá-lo. Não criar variações visuais novas.
